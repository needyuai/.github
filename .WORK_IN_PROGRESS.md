## ⚠️ Este repositório é PÚBLICO

Diferente da maioria da frota, `needyuai/.github` é público — este arquivo é legível por qualquer pessoa, sem login.

**Entradas aqui não citam referência de repositório privado.** Nada de `<repo-privado>#<número>` nem nome de branch de outro repositório. Descreva o escopo em prosa; o rastreio detalhado vive na issue ou no PR, onde o controle de acesso se aplica.

Isso não é excesso de zelo: o número de issue, sozinho, é pouco — em volume, revela cadência, estrutura interna e o que está em voo. A mesma disciplina que o site aplica ao mascarar referências internas na página pública vale aqui.

## Como usar

1. **Ao iniciar trabalho não-trivial**, adicione uma linha em "Em andamento".
2. **Ao terminar** — PR mergeado, trabalho descartado ou pausa indefinida — mova para "Concluído recentemente" (ou apague, se foi descartado).
3. **A cada 7 dias**, limpe entradas antigas de "Concluído recentemente".
4. **Antes de iniciar**, leia este arquivo (parte do D1).

## Convenções

- Timestamp `[YYYY-MM-DD HH:MM]`, hora local do owner.
- Identifique a sessão pelo assento: `<ferramenta>·SQ<n>` (ex.: `claude·SQ22`). Humano = iniciais.
- Linha: `[data] <ferramenta>·SQ<n> — <escopo> · branch <nome> · ETA <…>`.
- Ao concluir, referencie o PR **deste** repositório (público) ou o commit.
